# 需求池

来源说明：

- 「现有」指仓库当前已经实现或已有明确代码落点的能力。
- 「对标」指由 Cruxie 逆向拆解得出的改进项，编号对应 `docs/competitor-cruxie.md`「一、产品分析」里的缺口清单。

优先级定义：

- P0 必须实现：删掉之后产品不成立。
- P1 应该实现：显著影响体验、留存或转化。
- P2 可以实现：增量价值，排序靠后。

## 3. 版本切片

- V1.1 补齐体验短板：R-05 归因翻译层、R-07 拍摄引导、R-08 进度与预期、R-10 报告导出补分享卡。
- V1.2 建立量化语境：R-04 难度语境、R-06 分数标尺、R-19 维度雷达。
- V2.0 打通训练闭环与协同：R-12 训练闭环、R-13 同线对比、R-15 教练协同。
- V2.0+ 视数据决定：R-14 项目扩展。

---

## 4. 未纳入本期的候选

- 实时动作识别与现场语音提示：需要在岩馆做端侧推理，成本与场景收益暂不成比例。
- 岩馆排线与线路库：依赖场地数据合作，属于渠道问题，不是产品问题。
- 社交动态流：与「本地优先、隐私优先」的产品立场冲突，暂不引入。
