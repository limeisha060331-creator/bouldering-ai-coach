# 竞品分析：Cruxie

对标 cruxie.app。信息来自官网三个语言版本和 Google Play 商店页，抓取于 2026 年 10 月。

业务目标：给 CRUX 下一版本定位置。分析链路用「用户 → 场景 → 问题 → 解决方案 → 支撑点（RTB）」。下文未标「推断」的内容都能在官网找到出处。

档案

- 一句话定位：像卡拉 OK 打分一样给攀岩视频打百分制评分，并指出崩得最狠的那一段
- 主体 ORESHIHON Inc.，Android 7.0 及以上已上线，iOS 15.0 及以上即将推出
- 界面 7 种语言：日语、英语、中文、韩语、西班牙语、法语、德语
- 新用户送 3 次免费分析
- 单段视频上限 2 分钟，一段视频一次分析，只支持室内抱石
- 出分要几分钟到约 15 分钟
- 视频和结果仅本人可见，不共享，不用于训练模型

## 一、产品分析

### 1. 用户

画像

| 维度 | 判断 |
| --- | --- |
| 地域 | 全球。7 种语言同时覆盖日、欧美和中文市场 |
| 设备 | Android 先行，iOS 后补 |
| 项目 | 只做室内抱石 |
| 水平 | V2 到 V6（推断） |
| 年龄 | 18 到 40 岁（推断） |
| 训练方式 | 自主训练，没有固定教练 |

消费偏好

价格敏感度中等，用 3 次免费换第一次尝试，不直接卖订阅。新品牌没有背书可借，转化全靠首次分析的结果。消费发生在岩馆的碎片时间。官网在 FAQ 里单独承诺隐私，说明团队判断目标用户在意这件事。

潜在动因

| 动因 | 触发强度 | 依据 |
| --- | --- | --- |
| 控制感 | 强 | 官网原话：把靠感觉读的岩壁，变成能用数字读的岩壁 |
| 焦虑缓解 | 强 | 主页第一句是捕捉你攀爬崩溃的瞬间 |
| 奖励与补偿 | 强 | 百分制、保留 0.1 分、Top 3 个人最佳、每周最佳 |
| 自我实现 | 中 | 主打突破平台期 |
| 美感与自我呈现 | 无 | 没有分享卡、没有导出、没有作品集 |
| 归属与认同 | 无 | 没有社区、没有好友、没有教练协同 |

用户买的是控制感：把「我到底行不行」换成能比较的数字。这一条决定了它往后所有的取舍。

### 2. 场景

生活场景在岩馆，攀爬和休息的间隙。情绪场景是卡线焦虑、完攀后的自我确认。社交场景没有，没有分享、没有教练协同、没有社区，Instagram 只当更新公告栏。

价值判断上，攀爬虽然高频，但上传分析受免费额度和等待时长限制，实际是低频。对正在磕一条线的人，单次分析价值高，客单价撑得住。它用卡拉 OK 打分的经验解释攀岩分析，造出一个新场景，这是它最锋利的地方。

场景是否清晰：口号只讲一件事，具体到分数下滑最狠的那一段，磕过线的人一看就懂。

隐患在节奏。最需要它的地方是岩馆，而它要等几分钟到 15 分钟。

### 3. 问题

| 类型 | 用户问题 | Cruxie 的解决情况 |
| --- | --- | --- |
| 痛点 | 没有客观反馈，点评估赖教练在场 | 解决 |
| 痛点 | 看回放只知道掉了，不知道崩在哪 | 解决，自动定位 crux 并标秒数 |
| 痛点 | 不同难度的分数不可比 | 未解决，不记录路线难度 |
| 痒点 | 想在休息的几分钟内拿到结论 | 部分解决，最长等 15 分钟 |
| 痒点 | 想知道自己在不在进步 | 解决，本月与上月雷达叠加加周趋势 |
| 痒点 | 想把结论给教练看 | 未解决，没有导出 |
| 爽点 | 像卡拉 OK 一样被即时打分 | 解决，核心爽点 |
| 爽点 | 最好的一次被自动记住 | 解决，Top 3 加每周最佳 |

痛点解决得干净，爽点做得锋利，两个痒点上留了口子：难度语境和结论导出。这两处它做得到，只是不愿意做。让结果流出 App 会削弱留存。

### 4. 解决方案

功能层

3D 姿态估计跟 133 个关键点，覆盖全身、手指、面部，空中姿态也能还原。识别岩点，判断抓的是哪个点、从哪里起跳。按物理算四肢和关节的受力。评分分 5 个维度、每个 20 分：四点保持、流畅度、技术运用、重心位置、重心主导。时间轴分数曲线与视频联动，一键跳到 crux，播放器可叠加骨骼、受力、下一个抓点、雷达图。历史支持按日期和分数排序，支持本月与上月雷达叠加，有周趋势。排名上给本月 Top 3 个人最佳，自动选每周最佳，分数保留 0.1 分。

情绪层

机器打分不带人情，绕开了朋友点评不客观的问题。隐私承诺换信任，这是新公司拿到用户授权最短的路。0.1 分的精度让「再快一点」有抓手。完攀也要找弱点，避免用户在一次好成绩后失去目标。

社交层

空。别人靠分享传播，它靠隐私承诺建立信任，代价是没有自传播。

缺口

| 编号 | 缺口 | 缺在哪层 | 对应需求 |
| --- | --- | --- | --- |
| P1 | 只给分值，缺「扣分到身体发生了什么，再到下次改什么」的因果链 | 功能层 | R-05 |
| P2 | 等待时间不可预期，没有阶段进度 | 功能层 | R-08 |
| P3 | 上传前不校验，拍摄要求只写在 FAQ，废片率高 | 功能层 | R-07 |

| P5 | 有分数趋势，没有训练目标和 drill | 功能层 | R-12 |
| P6 | 一段视频一次分析，同一条线的多次尝试没法并排比 | 功能层 | R-13 |
| P7 | 教练看不到学员数据 | 社交层 | R-15 |

### 5. 支撑点（RTB）

| 维度 | 强度 | 依据 |
| --- | --- | --- |
| 技术证明 | 强 | 133 关键点、3D 姿态、岩点识别、物理受力。官网只给能力参数，没给精度和误差 |
| 信任背书 | 弱 | 没有机构认证、专家推荐或运动员代言 |
| 口碑效应 | 弱 | 没有用户评价、销量或复购数据，商店页也没突出用户量级 |
| 设计与细节 | 中偏强 | 官网克制清晰，多语言本地化到位，5 个评分轴与时间轴联动是想清楚了的 |
| 品牌势能 | 弱 | 2026 年新公司，没有品牌历史和行业地位 |

五条腿里只有技术证明站得住。技术被追平那天，用户没有理由留下。对我们来说，用设计与细节加真实口碑错位竞争，比硬拼姿态估计精度划算。

## 二、新产品上市

节奏是慢热型：Android 先跑通，iOS 延后，靠 3 次免费持续拉新，多语言官网同步铺开。预算分配、投放动作、商业结果都不公开。

内容策略值得学。它把「3D 姿态估计加物理受力计算」翻译成「像唱 K 一样给你打分」。技术参数没人看，生活隐喻才有人转。

## 三、营销传播

按背景、目标、策略、创意、执行、效果看，公开页面上只看得到前三项。动机推断是在 iOS 上线前用 Android 版验证需求、攒口碑。目标没有公开口径。策略是游戏化：评分、排名、每周最佳，用这些替代说服式文案。创意集中，官网只推一个主张，分数下坠的那一段就是你的 crux。执行薄，只押了官网、Google Play 和 Instagram 三个自有渠道。效果无公开数据。

表达和策略有参考价值，渠道选择没有。

---

## 四、品牌升级

不适用。品牌升级是系统性工程，对外重塑认知，对内调整战略和组织，由三类原因触发：认知过时、能力跟不上增长、环境与需求变化。Cruxie 是 2026 年新公司的新品牌，这三类原因都还没出现，公开信息里也没有换标或定位迁移的痕迹。

值得盯的信号是它从室内抱石扩到难度攀或速度攀。那会是一次多元化升级，到时按时间轴、问题链、升级动因三段跟。

---

## 五、结论

Cruxie 卖的是控制感，把模糊的自我怀疑换成可比较的数字。这一句解释它全部的选择：先给总分，因为要即时爽感；做排行榜和每周最佳，因为要用户回来；不做训练计划，因为计划是延迟收益，会冲淡爽感；放弃社交层，因为可以用隐私承诺换信任。

按这条逻辑推，它接下来会继续加固评分和对比，不会优先补 drill 和训练计划。这是我们的窗口期。

四件事可以做：

- 复用它的概念翻译法，把我们做的事说成一句用户五秒能懂的话，别讲技术。
- 它的 RTB 只有技术一条腿，我们用设计与细节加真实口碑错位打。
- 它没有自传播，我们把报告导出和分享卡做成传播元件，补上它缺的那一环。
- 它没解决难度不可比，我们记了 V 级，这是现成的差异点，该放大成定位，不要藏在筛选器里。

落地顺序：先补缺口清单里的 P1、P2、P3（对应 R-05、R-08、R-07），这三条是它最大的口子，不需要新的技术底座。再把 P4、P10 做成显性卖点（R-04、R-06、R-19）。最后用 P5 建它短期不会跟进的壁垒（R-12）。

条目与验收要点见 `docs/backlog.md`，版本切片见 `docs/PRD-v2.md`。
